讀本專案 vault 的 `WORKSPACE.md`「下一棒交接」節(路徑見開場簡報),
以**最上面**的區塊為準(舊區塊僅供考古)。

然後報三件事,**各一到兩句就好** —— ⛔ 不要長篇:

1. **現況** —— HEAD、工作樹是否 clean、有無進行中的任務包。
   ⚠️ 遠端一律用 `git ls-remote origin <分支>` 直接問,⛔ 不看本機 `origin/*` 快照。
   ⚠️ 交接章若寫「尚未 commit / 尚未 push」,先查證再信 —— 那類字樣有過期前例。
2. **下一手該做什麼、為什麼**(依交接章)。
3. **卡住的 / 需要我裁決的** —— 有兩個以上選項就列甲/乙/丙 + 你的建議與理由,⛔ 不自選。

⛔ 報完**停下等我**,不要開始動工。

## 常駐授權(本 session 有效)

往後這個 session 裡,五件套流程該派 `nr-planner` / `nr-implementer` / `nr-auditor` 的時候
**直接派,不用每次問我**。這是我本人的授權。

⚠️ 但下列三件仍要逐次問我,⛔ 不在本授權範圍內:
- `git commit` / `git push`(push 另有 `push-gate` 無條件擋)
- 動到已收案任務的裁定
- 超出當前任務包範圍的事
